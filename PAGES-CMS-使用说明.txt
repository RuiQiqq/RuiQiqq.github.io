祁睿作品集｜Pages CMS 使用说明

你现在在 Pages CMS 里看不到栏目，是因为仓库根目录还没有完整的 .pages.yml 配置，或者刚创建的是空配置。

本版本已经包含：
- .pages.yml：后台字段和上传位置
- content/portfolio-zh.json：中文网站内容
- content/portfolio-en.json：英文网站内容
- assets/js/content-loader.js：让网站读取 CMS 内容

第一次安装步骤：
1. 解压本压缩包。
2. 进入 GitHub 仓库 RuiQiqq.github.io。
3. 用本压缩包里的全部文件覆盖仓库根目录。
4. 特别确认仓库根目录能直接看到：
   .pages.yml
   content/
   index.html
   assets/
5. 等待 GitHub Actions / Pages 部署完成。
6. 回到 Pages CMS，重新打开仓库；必要时刷新页面。

后台会出现：
作品集内容
├─ 中文网站内容
└─ English Website Content

在中文网站内容中：
- “网站基本信息”可改姓名、职位、邮箱、简历等。
- “首页主要能力”可以点加号新增、删除或排序。
- “项目（点击加号可新增）”可以点加号新增项目。
- 每个项目内部可以上传封面、添加多个视频、多个图片、多个蓝图拆解和下载文件。

重要：
- 中文和英文是两份独立内容。新增项目时，最好在两边各新增一次，并使用相同项目 ID。
- 项目 ID 只能用英文小写、数字和横杠，例如 breach-brew。
- 图片和 PDF 会直接上传到 GitHub 仓库，不会存到其他收费数据库。
- 保存后 Pages CMS 会自动向 GitHub 提交一次 commit，GitHub Pages 通常需要几十秒到数分钟重新部署。
- 不要再编辑 EDIT-ME-English.js 或 EDIT-ME-Chinese.js；内容已移动到 content 文件夹。

多个视频：
- 项目的“主视频”用于首页或项目顶部。
- “多媒体画廊”可以点加号添加任意数量的视频或图片。
- 视频建议填写 YouTube/Bilibili 链接，不建议把大型完整视频上传到 GitHub。
- 5–15 秒的小型 VFX 展示可以上传 MP4/WebM。
